# `assets/docs/` — guia do usuário

**Responsabilidade:** o guia do usuário em cada idioma, mostrado pelo diálogo de ajuda.

## Porta de entrada

`ui/core/dialogs/user_guide_dialog.py` escolhe `guide_<locale>.md`.

## Arquivos

| Arquivo | Responsabilidade |
|---|---|
| `guide_en_US.md` | Lumenia Art Studio — User Guide |
| `guide_es_ES.md` | Lumenia Art Studio — Guía de Usuario |
| `guide_ja_JP.md` | Lumenia Art Studio — ユーザーガイド |
| `guide_pt_BR.md` | Lumenia Art Studio — Guia do Usuário |

## Regras

- Os quatro guias têm as mesmas seções; mudou um, mudam os quatro.
