# 🎨 Lumenia Art Studio — ユーザーガイド

**Lumenia Art Studio** へようこそ。高精度かつ超低ストローク遅延を誇る、ネイティブ **ALADYN C++20** エンジン搭載のプロフェッショナル向けデジタルペイント＆2Dコンセプトアートワークステーションです。

---

## ⚡ 1. システム概要

Lumeniaは、ビジュアルUI（PySide6）と高性能物理エンジン（SIMD AVX2最適化C++20）を厳密に分離した **ARCcC**（*Atomic Recursive Componentization by Contract*）アーキテクチャに基づいて設計されています。

- **スパースタイル（64×64）による無限解像度**: 実際の描画が存在する領域のみにメモリを割り当てる効率的なスパース構造を採用。
- **Catmull-Rom & Clark 補間**: 高速なペンストローク時でも途切れのない滑らかな描画応答を実現。
- **マルチドキュメント（MDI）対応**: 独立したネイティブエンジンインスタンスにより、複数作品を同時に快適編集。

## 🖌️ 2. 描画ツール一覧

| ショートカット | ツール | 機能概要 |
| :---: | :--- | :--- |
| **B** | **ブラシ** | 油彩、水彩、鉛筆、インクなどの物理特性を備えた主力描画ツール。 |
| **E** | **消しゴム** | アルファチャンネルを保持しながら滑らかにピグメントを消去。 |
| **U** | **図形ツール** | 矩形、楕円、多角形、星形のパス描画および塗りつぶし。 |
| **T** | **テキスト** | リアルタイムフォントプレビューによるラスターレイヤーへの文字挿入。 |
| **I** | **スポイト** | 1×1ピクセルまたは3×3／5×5領域平均での正確な色抽出。 |
| **G** | **塗りつぶし** | 許容値とアンチエイリアス設定に対応したスマート流し込み。 |
| **W** | **自動選択** | 色彩類似度に基づく連続／不連続選択範囲の作成。 |
| **Ctrl+T** | **自由変形** | 移動可能ピボット、8個のハンドル、バイキュービック補間による変形。 |

## 📐 3. パース定規＆対称機能

サイドバーの **幾何学＆対称** パネルから定規を有効化できます:
- **平面定規**: 直線、ベジェ曲線、等角（アイソメトリック）グリッド。
- **透視投影**: 1点透視、2点透視、3点透視。
- **6点魚眼曲面パース**: 360°全方位魚眼グリッドをリアルタイム投影。
- **対称スタジオ**: 自由ミラー、垂直ミラー、水平ミラー、ダブルミラー、ラジアル対称（3〜36軸）、万華鏡。

---

## 🎭 4. レイヤーとブレンドモード

- **階層化グループ管理**: 瞬時に開閉可能なネスト構造のレイヤーグループ。
- **対応ブレンドモード**:
  - *通常*, *乗算*, *スクリーン*, *オーバーレイ*, *ソフトライト*, *ハードライト*.
  - *比較（暗）*, *比較（明）*, *加算（リニア覆い焼き）*, *消去*.
- **高度な制作機能**: クリッピングマスク、透明度保護（アルファロック）、非破壊調整レイヤー。

---

## 🎨 5. カラーモードと色校正 (Soft Proofing)

メニューの **表示 > 色校正＆レンダリング** から設定可能:
- **色域シミュレーション**: CMYK（FOGRA39、US Web Coatedなど）や目標ディスプレイでの見え方をリアルタイム確認。
- **色覚多様性シミュレーション**: 1型（P型）、2型（D型）、3型（T型）、全色盲の見え方を再現。
- **ディープカラー（RGBA16F）**: 64ビット半浮動小数点処理とリニアガンマ補正によりグラデーションの段差を防止。

## ⌨️ 6. 主要ショートカット

- `Ctrl + N`: 新規ドキュメント
- `Ctrl + O`: ファイルを開く
- `Ctrl + S`: ドキュメントを保存
- `Ctrl + Shift + S`: 別名で保存
- `Ctrl + Z` / `Ctrl + Y`: 元に戻す / やり直す
- `Ctrl + =` / `Ctrl + -`: ズームイン / ズームアウト
- `Space + ドラッグ`: キャンバス移動（パン）
- `Ctrl + A` / `Ctrl + D`: すべて選択 / 選択解除
