# `assets/images/` — imagens da aplicação

**Responsabilidade:** o ícone do Lumenia (janela, splash, sobre, instalador).

## Porta de entrada

`resource_path("assets", "images", "icon_lumenia.png")`.

## Regras

- `icon_lumenia.ico` é o do executável e do instalador; `icon_lumenia.png` o da janela.
